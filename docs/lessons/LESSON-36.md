# 36. Ошибка API, безопасная смена ключа и тихий запуск

Ноль рекомендаций и отсутствие успешного анализа — разные результаты.
HTTP 401 означает отказ авторизации провайдера: требования вакансии при этом
вообще не оценены. Продолжать отправку остальных вакансий партии бессмысленно.

`collect_and_analyze` сначала сохраняет результат попытки и её статус в истории,
затем проверяет HTTP-статус. При ошибке провайдера исключение `ValueError`
передаёт управление обработчику общего прохода. Неотправленные вакансии
остаются в очереди. Сетевой сбой без HTTP-ответа тоже останавливает партию:
неизвестно, обработал ли сервер запрос, поэтому автоматического повтора нет.
Ошибки проверки содержимого при успешном HTTP-ответе рассматриваются отдельно.

Общий проход сохраняет отчёт и сообщает об ошибке в Telegram. Разовый режим
получает ненулевой код завершения и не объявляет успешные «Раскопки закончены».
Проверка с подставным HTTP 401 подтверждает: одна попытка вместо всей партии,
остальные записи продолжают ждать в очереди.

`examples.rotate_openai_key` принимает новое значение через стандартный ввод.
Перед заменой проверяет, что раскопки выключены, и делает запрос списка моделей,
который не запускает анализ вакансий. Затем меняет только ключ OpenAI в словаре
реквизитов, записывает временный файл с ограниченными правами, вызывает `fsync`
и атомарно заменяет основной файл через `os.replace`. Данные HH и Telegram
сохраняются. При отклонении ключа старый файл не меняется.

Служба перезапускается только если работала до замены: systemd должен заново
загрузить credentials. Отключённый поиск сам от этого не включается. Сообщения
инструмента не выводят ключи и тела ответов провайдера.

Ещё один источник шума — стартовое сообщение контроллера. Если служба
восстанавливается после сетевой ошибки, одинаковый статус снова приходит
пользователю. Теперь обычный старт записывается только в журнал. Ответы на
кнопки, уведомление о завершении партии и сообщения об ошибках сохраняются.
Тест запуска выключенного контроллера проверяет отсутствие отправок и поиска.
