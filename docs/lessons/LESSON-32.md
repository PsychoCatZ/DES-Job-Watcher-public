# 32. От поиска до Telegram за один проход

`run_once --telegram --live` соединяет поиск, загрузку полных карточек, Luna,
общий отчёт и отправку не более одной неотправленной карточки для рассмотрения.
Без `--telegram` отправки нет; без `--live` весь сценарий показывает только план.

Имена партий анализа заранее определяются по уникальному имени прохода и профилю.
`analyze_saved --output-directory` записывает каждую партию по переданному пути.
Если новых анализов нет, создаётся пустая папка партии: это корректный пустой
результат, а не причина подхватывать старые данные. `report_saved` получает
явный список этих партий и свой `--output-directory`. Telegram читает именно
этот отчёт, а не последнюю по времени папку.

Каждый дочерний процесс наследует секреты текущего PowerShell. Сценарий проверяет
необходимые переменные и привязку до начала поиска и платных запросов. Для токена
Telegram добавлено поле в `scripts/start_session.ps1`; значение можно пропустить,
если отправка не нужна. Значения остаются в текущем окне, на диск не записываются.

При ошибке этапа дальнейшие этапы останавливаются. Результаты остаются на месте;
автоматического продолжения, повторов оплаты и повторов отправки нет. Пустой
раздел для рассмотрения — успешный проход без отправки. Профессиональный разбор
пока остаётся в отчёте. Свежие карточки повторно перед отправкой не запрашиваются.

Проверка маршрутов в тесте заменяет `run_step` имитацией: ни HH, ни Luna, ни
Telegram не вызываются. Тест проверяет передачу точных партий в отчёт и отчёта
в доставку, а также остановку при ошибке анализа. Реальный общий проход
подтверждается отдельно с вводом ключей владельцем.
